# ASTHE (An Sonic the Hedgehog Engine)
This is an Sonic engine, made just for fun!
It haves code parts from [Psych Engine][psych_engine]... I'm planning on replacement for all this stuff.

Help would be appreciated! Call me on Discord if you want to talk with me! (`@unreal.sunnydev`, [link to my profile][sunnydev_discord])

<details>
<summary><h2>Pre-Build Downloads</h2></summary>

You can download the latest pre-builds directly from the [Actions tab][repo_actions]\
Please note that official standalone releases won't be available until the game reaches a playable state.
</details>

<details>
<summary><h2>Compiling resources</h2></summary>

You need to clone the repository, and you must need Git installer before starting\
[Read this guide on the wiki for more details!][docs_compiling]

To clone the repo, run this on a terminal:\
`git clone https://github.com/unrealsunnydev/ASTHE.git`
</details>

<details>
<summary><h2>Modding</h2></summary>

Modding stuff currently are broken, because Polymod framework can't\
find mods on build releases, but you can read the [Modding Docs][docs_modding]\
to learn more about how modding in this game works
</details>
